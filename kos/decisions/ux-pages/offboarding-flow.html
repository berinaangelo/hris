Offboarding Flow — three recommendations

What "Offboard" actually opens on decisions/ux-pages/employee-detail.html — the entry point that was shown but left unbuilt when Employee Detail was decided. Not on the original build list (same as Org Chart, this was requested ad hoc). Subject is Jonas Rivera, the QA Engineer already shown carrying the "Offboarded" badge on decisions/ux-pages/people-directory.html — this flow is how he got there. What changes across the three is how much of the real process (last working day, reason, equipment/access/final-pay clearance) is captured, and whether "Offboarded" is set instantly or only once clearance is actually done.

Reused, not re-decided here: decisions/ui/color-palette-ink-and-amber.md, decisions/type-system-neutral-and-efficient.md, decisions/ui/badge-system-four-categories.md — "Active" shows no badge, only "Offboarded" (Neutral) does, per that spec's own "badges are for deviation" rule. Reason for separation, last working day, and a four-item clearance checklist (equipment returned, access revoked, final pay & clearance, exit interview) are this page's own invented scope — no PLAN.md names them. Decided 2026-08-23: Option 3 chosen — see decisions/ui/offboarding-flow-schedule-clearance-tracker.md. Its transitional "Offboarding" status (Caution), distinct from the terminal "Offboarded" (Neutral), is now defined in badge-system-four-categories.md's mapping table, and People Directory was updated the same day to show it (Jonas Rivera demonstrates it there — visible by default, since he's still working — alongside a new example of the terminal state).

Why this one

Cheapest build — the seventh reuse of the same right-side drawer mechanic already shipped for Payroll Run Detail, Time & Attendance, Rate Tables, Loan Ledger, Hired Handoff, and the Job Opening form. One form, one confirm, done.

Best when

The separation is immediate (last day is today, or already passed). Weaker when the last working day is genuinely in the future, like Jonas's here — the record reads Offboarded three weeks before he's actually gone, and equipment/access/final-pay clearance has nowhere to be tracked.
