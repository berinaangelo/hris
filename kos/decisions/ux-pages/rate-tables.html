Rate Tables — three recommendations

The HR-Admin screen under Company → Payroll → Rate Tables, where SSS/PhilHealth/Pag-IBIG/BIR withholding are stored as admin-editable data (decisions/statutory-deductions-as-editable-data-not-code.md) instead of hardcoded formulas — this is the "separate not-yet-built page" referenced from Payroll Run Detail's read-only statutory section. All three options below hold the same four agencies and the same underlying figures; what changes is how you get from "browsing the current rates" to "editing one agency's table."

Illustrative rates — not verified against current circulars. SSS/PhilHealth/Pag-IBIG figures approximate recent public bracket tables for shape only; BIR uses TRAIN law's withholding structure. Do not use these numbers for real payroll — HR would type in the actual published table when this ships. No live computation is wired in any option; edited values shown here don't recalculate anything. Viewing persona: Andrea Cruz, HR Admin, today is Aug 22, 2026. Per decisions/ui/employee-detail-inline-edit-with-reserved-tabs.md's established convention: a table sitting on a page you might just be browsing gets an explicit Edit toggle so nothing changes by accident (Options 1 and 2); a table opened specifically to edit it — a dedicated drawer (Option 3) — is directly editable, no extra toggle needed. No effective-dated version history is modeled — an edit simply replaces the current table, per decisions/rails-skinny-models-behavior-in-interactors.md keeping payroll's own "no computed history, only current lookups" scope.

Why this one

One table on screen at a time, at full width — the widest tables here (SSS, BIR) get the most room to breathe, and there's zero ambiguity about which agency you're looking at or editing. The segmented control is a lighter-weight switcher than a second row of top-level tabs.

Trade-off

Can't see two agencies' "last updated" dates side by side without clicking between them — the exact comparison ("which of these four is stalest?") this screen exists to make easy is one click short of being answerable at a glance.
