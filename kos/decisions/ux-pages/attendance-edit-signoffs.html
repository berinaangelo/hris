Attendance Edit Sign-offs

The admin-only inbox for the optional oversight step on manager-made manual attendance edits — Company → Attendance Sign-offs (team_attendance_edit_approvals_path). Approve/Reject is audit-only: the edit already took effect the moment the manager saved it, this screen never gates payroll or reverts a punch.

Reused, not reinvented: fields match Team::AttendanceEditApprovalsController exactly — employee, date, the edited clock in/out, who edited it, and (for decided items) the four-category status badge. No before/after diff exists to show (the record only stores its current values), and no decision-note field exists on RejectEdit — not invented here. Only reaches this inbox when a manager's edit and the company has attendance_approvers_enabled on; an admin's own edits never need sign-off. See decisions/time-attendance-correction-request-and-manual-edit.md.
