Attendance Corrections

The employee's own attendance-correction requests, under Me → Attendance (nav slot already reserved in navigation_presenter.rb, path attendance_correction_requests_path). Distinct from Time & Attendance (Company/Team, HR-Admin and manager facing — approve/reject already folded into that page); this is the self-service side: file a request, see its status.

Reused, not reinvented: same "List + Modal Form" shape as Time Off (decisions/ui/time-off-list-plus-modal.md) — request history is the default view, filing a request is occasional so it lives behind a button. Fields match the real form exactly (attendance_correction_requests/new.html.erb): date, an optional corrected clock in, an optional corrected clock out, and a required reason. The model requires at least one of the two clock times — demoed below, not invented. Approval is single-level only, same as every other request type in the system (decisions/approval-chains-scrapped-fallback-design.md) — goes to the employee's manager, or "an admin" if they have none.
