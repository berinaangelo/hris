Chose "Neutral & Efficient" for the HRIS typography — a neo-grotesque
sans pairing — over two other proposed options ("Public Record":
humanist sans; "Confident & Structured": slab serif + sans). Full
comparison with specimens on a payroll register and review comment:
https://claude.ai/code/artifact/ad820667-965d-4c66-bdb1-ff7ba1cdac19

**Type roles:**
- Display / headings: Archivo, weight 700–800
- Body / UI: Work Sans, weight 400–500
- Data / tabular (numerals — payroll amounts, dates, KPI scores): IBM
  Plex Mono, weight 400–500, fixed across every typography option
  considered — column alignment is a legibility requirement, not a
  style choice, same reasoning as
  [[statutory-deductions-as-editable-data-not-code|data-not-code]] being
  a recurring project principle.

Why this one: neo-grotesques carry no stylistic "opinion," which fits a
system whose screens are dominated by dense rows of names and currency
(payroll registers, employee lists, reports) — the typeface disappears
so the content is what people actually read. It also matches the
register of [[color-palette-ink-and-amber|Ink & Amber]]: both read as
direct and unfussy rather than warm, so type and color reinforce one
identity instead of pulling apart.
